13.1 Introduction

🛒 The Fruit Cart: Framing Two Unknowns

Page 85
🍎 The Market Scenario

Radha visits a fruit vendor cart where mangoes cost ₹60/kg and bananas cost ₹50/kg. She purchases a certain quantity of both fruits and pays a total sum of ₹280.

  • Let $x =$ number of kilograms of mangoes purchased
  • Let $y =$ number of kilograms of bananas purchased
  • Cost of mangoes $= 60x$ and cost of bananas $= 50y$
  • Total purchase equation: $60x + 50y = 280$
🔍 Mathematical Dissection
$$60x + 50y = 280$$
  • LHS and RHS Harmony: Both sides represent the identical quantity—the total expenditure in rupees.
  • Two Variables: Two distinct quantities ($x$ and $y$) can vary, but their combined cost is anchored to 280.
  • Linear Degree: The exponent of both $x$ and $y$ is strictly $1$. Hence it represents a linear relation.

13.1.1 Standard Form

📐 The General Standard Form: $ax + by + c = 0$

Page 86
$$ax + by + c = 0 \quad \text{where } a, b, c \in \mathbb{R} \text{ and } a^2 + b^2 \neq 0$$
📌 Real Coefficients

$a$ and $b$ are the coefficients of $x$ and $y$ respectively, and $c$ is the constant term. They can be integers, fractions, or irrational numbers.

⚡ Clearing Fractions

$\frac{1}{4}x + \frac{3}{5}y - \frac{1}{2} = 0$ is in standard form. Multiplying by $\text{LCM}(4,5,2)=20$ yields integer coefficients: $$5x + 12y - 10 = 0$$

🏷️ Special Case: One Variable

$4x + 7 = 0$ is a valid linear equation in two variables written as: $$4x + 0 \cdot y + 7 = 0$$ where $a=4, b=0, c=7$.

✍️ Expressing Equations in Standard Form

Page 86
(i) $5x + 2y = 2.7$
  • Rearrange: $5x + 2y - 2.7 = 0$
  • Coefficients: $\mathbf{a = 5,\ b = 2,\ c = -2.7}$
  • Alternative: $-5x - 2y + 2.7 = 0$ with $a=-5, b=-2, c=2.7$
(ii) $\frac{x}{2} - 4 = \frac{3}{2}y$
  • Rearrange: $\frac{1}{2}x - \frac{3}{2}y - 4 = 0$
  • Coefficients: $\mathbf{a = \frac{1}{2},\ b = -\frac{3}{2},\ c = -4}$
  • Clear denominators ($\times 2$): $x - 3y - 8 = 0$
(iii) $4 = 1.5x - 1.3y$
  • Rearrange: $1.5x - 1.3y - 4 = 0$
  • Coefficients: $\mathbf{a = 1.5,\ b = -1.3,\ c = -4}$
  • Multiply by 10 for integers: $15x - 13y - 40 = 0$
(iv) $3y = 5$
  • Include missing variable $x$: $0 \cdot x + 3y - 5 = 0$
  • Coefficients: $\mathbf{a = 0,\ b = 3,\ c = -5}$
  • Represents a horizontal line parallel to the $x$-axis.

13.2.1 Algebraic Meaning

✨ What is a Solution to $ax + by + c = 0$?

Page 88
📖 Formal Definition

A solution of a linear equation in two variables is an ordered pair of real numbers $(u, v)$ such that substituting $x = u$ and $y = v$ makes $\text{LHS} = \text{RHS}$.

$$\text{Testing for } 3x + 2y = 12:$$
  • For $(2, 3)$: $3(2) + 2(3) = 6 + 6 = 12$ ✅ Solution!
  • For $(4, 0)$: $3(4) + 2(0) = 12 + 0 = 12$ ✅ Solution!
  • For $(1, 3)$: $3(1) + 2(3) = 3 + 6 = 9 \neq 12$ ❌ Not a solution!
♾️ Infinitely Many Solutions

How many solutions exist for a single linear equation in two variables?

For any assigned value $u$ for $x$: $$y = \frac{12 - 3u}{2}$$ Since $u$ can be any real number on the continuous number line, there exist infinitely many pairs $(x, y)$ that satisfy the equation.
  • Ordered pairs $(0, 6)$, $(1, 4.5)$, $(4, 0)$, $(-2, 9)$ all satisfy $3x+2y=12$.
  • Order strictly matters: $(2, 3) \neq (3, 2)$.

13.2.2 Geometric Meaning

📈 Every Solution is a Point on the Line

Page 88–90
🎯 The Core Duality
  • Every solution $(x, y)$ of $ax + by + c = 0$ corresponds to a unique point on its straight line graph.
  • Conversely, every point on the line has coordinates that satisfy the algebraic equation.
  • Points lying outside the line never satisfy the equation.
Fastest Way to Plot a Line (Intercepts):
  1. Put $x = 0 \implies$ find $y$-intercept $(0, y_0)$
  2. Put $y = 0 \implies$ find $x$-intercept $(x_0, 0)$
  3. Connect these two points with a straight line.

💡 Special Case: When Constant $c = 0$

Page 91–92
🗣️ The Four Friends Discussion

Ranju, Meena, Farhan, and Toshi analyzed what happens when the constant term $c = 0$ in $ax + by + c = 0$:

  • Ranju: If $c = 0$, substituting $(0,0)$ gives $a(0) + b(0) = 0$. The equation is identically satisfied!
  • Farhan: For $2x + 3y = 0$, $x=0 \implies y=0$. Hence it passes through $(0,0)$.
  • Toshi: If $b=c=0 \implies 5x = 0 \implies x = 0$ (the $y$-axis itself).
  • Meena: If $a=c=0 \implies 7y = 0 \implies y = 0$ (the $x$-axis itself).
🔑 Fundamental Theorem of Origin Lines
$$ax + by = 0 \iff (0, 0) \text{ lies on the line}$$

Whenever $c = 0$, the straight line must pass through the origin $(0, 0)$, regardless of the non-zero values of $a$ and $b$.

13.3.1 Slope & Steepness

🚵 Understanding Steepness: Rise over Run

Page 94–96
🚴 Cycling Up a Hill: Rise and Run

Walking on flat ground requires minimum effort. As hills get steeper, effort rises drastically. In mathematics, steepness is measured by slope (or gradient).

  • Run $(\Delta x)$: Horizontal displacement $(x_2 - x_1)$. Moving right is positive; moving left is negative.
  • Rise $(\Delta y)$: Vertical displacement $(y_2 - y_1)$. Moving up is positive; moving down is negative.
$$\text{Slope } (m) = \frac{\text{Rise}}{\text{Run}} = \frac{y_2 - y_1}{x_2 - x_1}$$

13.3.1 Classifying Slopes

🧭 The Four Geometric Behaviors of Slope

Page 100–101
1. Positive Slope ($m > 0$) ↗️

Line climbs upward from left to right. As $x$ increases, $y$ increases. Example: $y = 2x + 1$ ($m = 2$: 1 unit right $\implies$ 2 units up).

2. Negative Slope ($m < 0$) ↘️

Line descends downward from left to right. As $x$ increases, $y$ decreases. Example: $y = -3x + 4$ ($m = -3$: 1 unit right $\implies$ 3 units down).

3. Zero Slope ($m = 0$) ➡️

Horizontal line parallel to the $x$-axis. Vertical rise is zero ($\Delta y = 0$). $y$ remains constant everywhere. Example: $y = 5$.

4. Undefined Slope ($m$ is Undefined) ⬆️

Vertical line parallel to the $y$-axis. Horizontal run is zero ($\Delta x = 0$). Since division by zero is undefined, slope is undefined. Example: $x = 2$.

13.3.2 Slope-Intercept

📐 Derivation: Why $m$ Represents the Slope

Page 98–99
$$y = mx + d \quad [m = \text{slope}, \ d = y\text{-intercept}]$$
🔬 Proof that $m$ is the Slope

Let points $A(x_1, y_1)$ and $B(x_2, y_2)$ lie on the line $y = mx + d$. Then: $$y_1 = mx_1 + d \quad \text{and} \quad y_2 = mx_2 + d$$ Calculate the slope between points $A$ and $B$: $$\frac{y_2 - y_1}{x_2 - x_1} = \frac{(mx_2 + d) - (mx_1 + d)}{x_2 - x_1} = \frac{m(x_2 - x_1)}{x_2 - x_1} = m$$ Thus, the coefficient of $x$ is identically equal to the slope!

🔄 Converting Standard to Slope-Intercept

Given $ax + by + c = 0$ with $b \neq 0$: $$by = -ax - c \implies y = \left(-\frac{a}{b}\right)x + \left(-\frac{c}{b}\right)$$

  • Slope: $m = -\frac{a}{b}$
  • $y$-intercept: $d = -\frac{c}{b}$ (cuts $y$-axis at $(0, -\frac{c}{b})$)
  • $x$-intercept: Set $y=0 \implies x = -\frac{c}{a}$

13.4 Linear Systems

🍱 Pair of Linear Equations in Two Variables

Page 103–105
🫓 The Paratha & Dahi Problem

A dhaba menu features two bundled offers:

  • Order 1: 1 Paratha $+ 2$ Bowls Dahi $= ₹90$
  • Order 2: 2 Parathas $+ 7$ Bowls Dahi $= ₹260$
$$\begin{cases} 1p + 2d = 90 \\ 2p + 7d = 260 \end{cases}$$

A single equation has infinite solutions. But both equations together constrain the prices to a single common pair $(p, d)$.

📜 General Mathematical Definition
$$\begin{cases} a_1 x + b_1 y + c_1 = 0 \\ a_2 x + b_2 y + c_2 = 0 \end{cases}$$

Where $a_1, b_1, c_1, a_2, b_2, c_2 \in \mathbb{R}$ and $a_1^2 + b_1^2 \neq 0$, $a_2^2 + b_2^2 \neq 0$.

  • Simultaneous Solution: An ordered pair $(x_0, y_0)$ that satisfies both equations at the same time.

13.5.1 Algebraic Methods

🔄 The Method of Substitution

Page 106–107
Step 1: Express Variable

Select one equation and express one variable purely in terms of the other.

Given: $x + 2y = 3$ (Eq. 2)
$$\implies \mathbf{x = 3 - 2y}$$
Step 2: Substitute & Solve

Substitute this expression into the other equation ($7x - 15y = 2$):

$$7(3 - 2y) - 15y = 2$$ $$21 - 14y - 15y = 2$$ $$-29y = -19 \implies \mathbf{y = \frac{19}{29}}$$
Step 3: Back-Substitute

Plug the value of $y$ back into the isolated expression for $x$:

$$x = 3 - 2\left(\frac{19}{29}\right)$$ $$x = \frac{87 - 38}{29} = \mathbf{\frac{49}{29}}$$ Solution: $\left(\frac{49}{29}, \frac{19}{29}\right)$

13.5.1 Algebraic Methods

✂️ The Method of Elimination

Page 107–109
💼 Example 9: Incomes & Expenditures

Incomes ratio is $9:7$ ($9x, 7x$) and expenditures ratio is $4:3$ ($4y, 3y$). Each saves ₹2000/month:

$$\begin{cases} 9x - 4y = 2000 \quad \text{--- (1)} \\ 7x - 3y = 2000 \quad \text{--- (2)} \end{cases}$$
  • Multiply to match $y$-coefficients:
  • $\text{Eq. (1)} \times 3 \implies 27x - 12y = 6000$
  • $\text{Eq. (2)} \times 4 \implies 28x - 12y = 8000$
🎯 Elimination by Subtraction

Subtracting the two balanced equations cancels $y$ completely:

$$(28x - 27x) - (12y - 12y) = 8000 - 6000$$ $$\mathbf{x = 2000}$$

Substitute $x = 2000$ into Eq. (1): $$9(2000) - 4y = 2000 \implies 4y = 16000 \implies \mathbf{y = 4000}$$

Monthly Incomes: $9(2000) = \mathbf{₹18,000}$ and $7(2000) = \mathbf{₹14,000}$

Ratio Conditions

⚖️ Nature of Solutions: The Ratio Test

Page 110–112
1. Unique Solution
$$\frac{a_1}{a_2} \neq \frac{b_1}{b_2}$$
  • Lines have different slopes.
  • They intersect at exactly one point $(x_0, y_0)$.
  • System is consistent and independent.
2. Infinitely Many Solutions
$$\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$$
  • One equation is a constant multiple $k$ of the other.
  • Lines are coincident (identical).
  • System is consistent and dependent.
3. No Solution
$$\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$$
  • Lines have equal slopes but different intercepts.
  • Lines are strictly parallel (never meet).
  • System is inconsistent.

📊 Graphical Intersection of Two Lines

Example 11: $x + 3y = 6$ & $2x - 3y = 12$

Construct two coordinate tables:

Line 1 ($x + 3y = 6$):
$(0, 2)$ and $(6, 0)$

⭐ Key Worked Exemplars from Chapter Exercises

Page 117, 118, 120
1. Taxi Fare Problem

$10\text{ km} \to ₹155$, $15\text{ km} \to ₹220$. Find fixed fare ($x$), per-km charge ($y$), and cost for $25\text{ km}$.

$$x + 10y = 155, \quad x + 15y = 220$$ Subtract: $5y = 65 \implies \mathbf{y = ₹13/\text{km}}$
$x = 155 - 130 = \mathbf{₹25}$ (fixed)
For $25\text{ km}: 25 + 25(13) = \mathbf{₹350}$
2. Cat and Stool Puzzle

From diagrams: Cat on stool to ground is $85\text{ cm}$; Stool with cat on floor is $25\text{ cm}$. Find stool height ($S$).

Let $S = \text{stool}, C = \text{cat}$.
$$\begin{cases} S + C - 0 = 85 \\ S - C = 25 \end{cases}$$ Add equations: $2S = 110$
$$\mathbf{S = 55\text{ cm}} \quad (C = 30\text{ cm})$$
3. Celsius to Fahrenheit

$F = \frac{9}{5}C + 32$. Is there a temperature numerically identical in both scales ($F = C$)?

Substitute $F = C$:
$$C = \frac{9}{5}C + 32 \implies C - \frac{9}{5}C = 32$$ $$-\frac{4}{5}C = 32 \implies \mathbf{C = -40^{\circ}}$$ $$\mathbf{-40^{\circ}C = -40^{\circ}F}$$

Chapter 13 Summary

📋 Master Summary Checklist

Page 122
✅ Foundations of Linear Lines
  • Standard Form: $ax + by + c = 0$ ($a, b$ not both zero). Represents a straight line on the Cartesian plane.
  • Infinitely Many Solutions: A single linear equation in two variables has an infinity of ordered pairs $(x, y)$.
  • Geometric Duality: Every solution is a point on the line; every point on the line is a solution.
  • Slope ($m$): $\text{Rise}/\text{Run} = \frac{y_2 - y_1}{x_2 - x_1}$. Slope-intercept form: $y = mx + d$.
✅ Systems of Two Linear Equations
  • Algebraic Methods: Method of Substitution and Method of Elimination reduce two unknowns to one.
  • $\frac{a_1}{a_2} \neq \frac{b_1}{b_2}$ : Unique solution $\longleftrightarrow$ Intersecting lines.
  • $\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$ : No solution $\longleftrightarrow$ Parallel lines.
  • $\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$ : Infinitely many solutions $\longleftrightarrow$ Coincident lines.
